백오피스 권한이 없습니다

로그인은 됐지만 이 계정은 어드민 명단에 없습니다. 아래 사용자 ID 를 전달하면 명단에 추가할 수 있습니다 — 명단은 마이그레이션으로 넣고, 넣은 뒤에는 다시 로그인해야 반영됩니다.

서버는 이 ID 로 user_identity 에서 provider 와 식별자를 찾아 명단에 넣습니다. 절차는 scripts/setup-admin.md 에 있습니다.

지역 혜택

지역에 붙는 혜택 뱃지입니다. 7대 혜택이고, 누르면 대상·기간·신청법을 보는 상세 화면이 열립니다. 지역마다 다르게 보입니다 — 완도에서 보이는 것과 가평에서 보이는 것이 다릅니다.

분류 정책명 / 뱃지 대상 지역 기간 확인일 노출 편집
