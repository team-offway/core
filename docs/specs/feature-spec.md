# OffWay 기능 명세 (v0.1 · MVP)

- 상태: 초안 (디자인·설계 논의용)
- 범위: **1차 데모(Must-have)**. Nice-to-have는 §7.
- 대상 독자: 기획·디자이너·개발
- 관련: [external-api-inventory.md](../external-api-inventory.md)

---

## 0. 설계 원칙

- **입력은 "의도"만, 조합은 서버가.** 사용자는 연차·출발지·무드만. 파라미터 조합은 OffWay가 대신한다.
- **검색이 아니라 조립.** "어디 갈까"가 아니라 "며칠 쉴 수 있나 → 완성형 코스".
- **공공데이터 재료 + 자체 레이어.** raw 그대로 노출 금지(이미지 CDN·집계·큐레이션).
- **한 화면 = 한 결정.** 각 스텝은 사용자가 결정할 것 하나만 묻는다.

---

## 1. 화면 목록 (디자이너가 그릴 것)

| # | 화면 | 핵심 내용 |
|---|---|---|
| S1 | **연차 입력(온보딩)** | 달력 + 연차 일수 · 이동수단 선택 |
| S2 | **가용시간 & 샌드위치** | 산출된 가용시간 카드 + 황금 연차일 추천 리스트 |
| S3 | **지역 추천** | 도달 가능 인구감소지역 카드 리스트(한산/인기 뱃지) |
| S4 | **코스 상세** | 날짜별 타임라인 + 지도 동선 + 혜택 뱃지 + 비용 |
| S5 | **저장/공유** | 완성 코스 저장·이미지 공유 |

> 흐름: S1 → S2 → S3 → S4 →(S5). S2는 "샌드위치 추천"으로 진입 시 시작점이 될 수도 있음(역방향).

---

## 2. 핵심 플로우 (유저 여정)

```
S1 연차 입력 ──▶ S2 가용시간 ──▶ S3 지역 추천 ──▶ S4 코스 상세 ──▶ S5 저장/공유
   연차·이동수단      LNT·샌드위치       도달 지역·한산도       타임라인·혜택·비용
```

---

## 3. 기능별 명세

각 기능: **유저스토리 · 화면 · 입력 · 상태 · 표시요소(디자이너) · 데이터 · 예시**

### F1. 가용시간(LNT) 산출 — `leave`
- **유저스토리**: "이 연차로 실제 몇 시간, 어디까지 갈 수 있는지 즉시 알고 싶다."
- **화면**: S1 입력 → S2 결과 카드
- **입력**: 연차 일수, 출발일(또는 요일), 반차 여부(선택), 퇴근시각(선택), 이동수단
- **상태**: 기본(입력 대기) / 계산중 / 결과 / 공휴일 미확정(먼 미래) 안내
- **표시요소**: `가용시간(예: 72시간)` 대형 숫자, `여행 가능 구간(목 18:00~일 23:00)`, `이동 한계(3시간 이내)`, 시각적 타임바
- **데이터**: 특일정보 API(공휴일·대체공휴일)
- **예시**: `금요일 연차 1일` → "목 퇴근~일 밤 **72시간**, 출발지 기준 **3시간 이내** 이동 가능"

### F2. 샌드위치 연휴 탐지 — `leave`
- **유저스토리**: "달력 안 뒤지고, 최소 연차로 최대로 쉴 수 있는 날을 추천받고 싶다."
- **화면**: S2 하단 추천 리스트(또는 별도 진입점)
- **입력**: 조회 범위(기본 향후 6개월), 보유 연차(선택)
- **상태**: 결과 리스트 / 추천 없음(해당 기간 없음)
- **표시요소**: 카드당 `연차 사용일(5/2 월)`, `총 휴식일수(4박5일)`, `효율(연차 1일=휴식 5일)`, `구간 미니 캘린더`
- **데이터**: 특일정보 API
- **예시**: "5/1(노동절·금) + **5/2 연차** + 5/3~4 주말 + 5/5(어린이날) = **5일 휴식**"

### F3. 인구감소지역 추천 — `trip`
- **유저스토리**: "내 시간 안에 갈 수 있는, 덜 붐비는 로컬 여행지를 골라주면 좋겠다."
- **화면**: S3 지역 카드 리스트
- **입력**: LNT(F1), 출발지 좌표, 무드칩(선택)
- **로직**: ①도달시간 필터 → ②TourAPI `totalCount`로 콘텐츠 충분성(부족 시 인접 50km) → ③방문자수/집중률 랭킹 → ④무드칩(lclsSystm) 필터
- **상태**: 로딩 / 결과 / 결과 없음(범위 확장 제안) / 인접지역 포함 안내
- **표시요소**: 지역 카드 = `대표 이미지`, `지역명(완도군)`, `도달시간(2시간 40분)`, `한산도 뱃지(평일 여유/보통/붐빔)`, `대표 관광지 3개 썸네일`
- **데이터**: `region` 시드(89) · TourAPI · 관광빅데이터(방문자·집중률) · TMAP(도달시간)
- **예시**: "강남 출발 · 72시간 → **완도군(2h40m, 평일 여유)** · 신안군 · 고흥군…"

### F4. 코스(동선) 자동 생성 — `itinerary`
- **유저스토리**: "관광지 하나하나 안 찾고, 동선까지 짜인 하루 코스를 받고 싶다."
- **화면**: S4 타임라인 + 지도
- **입력**: 선택 지역, 가용시간, 무드칩
- **로직**: seed 관광지 → `locationBasedList2`(주변·`dist`) → `detailIntro2`(운영시간·휴무일)로 평일 방문 검증 → TMAP 경유지 최적화 → 오전/점심/오후/저녁 슬롯 배치
- **상태**: 생성중 / 결과 / 일부 장소 휴무(대체 제안) / 코스 편집(순서 변경·삭제·추가)
- **표시요소**: 타임라인 = 시간블록별 `장소 카드(사진·이름·유형)`, 카드 사이 `이동시간(자차 15분)`, `평일 오픈 뱃지`, 상단 `지도 동선 토글`
- **데이터**: TourAPI(위치기반·소개정보) · TMAP(경로/경유지) · TAGO(대중교통 선택)
- **일정 밀도(사용자 선택)**: **널널 = 하루 2~3개** · **빡빡 = 하루 5~6개**
- **코스 상한**: **당일치기 / 1박2일 / 2박3일 (최대 2박3일)**
- **콘텐츠 충분성**(실측 기반): 필요 볼거리 = 일수 × 밀도.
  - 2박3일 **빡빡 ≈ 15~18개** · **널널 ≈ 6~9개**
  - 지역 볼거리(관광지+문화+레포츠) `≥18` → 빡빡 2박3일까지 OK · `9~17` → 널널만/일수 축소 · `<9` → 인접 50km 묶기
  - (실측: 89곳 대부분 30~60개 → 빡빡 2박3일도 여유. 완도38·정선57·고흥59·옹진45. 영양(10)급 초소도시만 널널 or 확장)
- **예시**: "10:00 청산도 → (자차 12분) 12:30 완도타워 전망대 → 13:30 전복 맛집 → …"

### F5. 정책 혜택 매칭 — `policy`
- **유저스토리**: "내 여행에 되는 정부 혜택을 알아서 찾아 붙여주면 좋겠다."
- **화면**: S4 코스 내 혜택 섹션 + 비용 요약
- **입력**: 코스(지역·날짜·교통), 사용자 속성(선택: 중소기업 근로자 등)
- **로직**: 7대 혜택을 **4축(지역/기간/대상/교통)** 으로 매칭 → 적용 가능한 것만 뱃지
- **상태**: 적용 가능 혜택 / 조건 미충족(사유 안내) / 사전신청 필요 안내
- **표시요소**: `혜택 뱃지(디지털관광주민증·반값여행…)`, `예상 절감액(-3만원)`, `종합 비용 재계산`, 뱃지 탭 → 상세/신청 링크
- **데이터**: **정책 seed(수동 적재)** · `region` 플래그(인구감소·디지털관광주민증 44 등)
- **예시**: "완도 = 인구감소지역 → **디지털관광주민증(가맹점 할인)** · **반값여행(50% 환급)** 적용 가능 · 예상 절감 **-6만원**"

### F6. 테마/유형 필터 — 공통
- **유저스토리**: "결과 안에서 내 취향(자연/맛집 등)으로 우선순위를 바꾸고 싶다."
- **화면**: S3·S4 상단 칩 바
- **입력**: 무드칩 1~3개
- **로직**: 칩 1개 → lclsSystm 코드 묶음(OR) 매핑
- **표시요소**: 칩 6~8개(자연·역사·체험·맛·레저·축제·힐링), 선택 시 결과 재정렬
- **비고**: 동반유형(연인·가족)은 공공데이터 부재 → §7

## 5. 공통 UI 규칙

- **한산도 뱃지**: 평일 여유(초록) / 보통(노랑) / 붐빔(빨강) — 관광빅데이터 집중률 기반
- **혜택 뱃지**: 지역/기간/대상/교통 매칭된 것만. 사전신청 필요 시 별도 아이콘
- **평일 오픈 뱃지**: 소개정보 휴무일 파싱 결과. 자연물은 "상시개방"
- **이동시간**: 자차 기본, 대중교통 토글 시 TAGO 기반
- **이미지**: 원본 X → CDN 리사이즈 썸네일

## 6. 데이터 소스 매핑

| 기능 | 사용 데이터/API |
|---|---|
| F1·F2 | 특일정보 |
| F3 | region seed · TourAPI · 관광빅데이터 · TMAP |
| F4 | TourAPI(위치기반·소개정보) · TMAP · TAGO |
| F5 | 정책 seed(수동) · region 플래그 |
| F6 | lclsSystm(TourAPI 분류) |

## 7. Out of Scope (Nice-to-have)

- 반차·퇴근 후 0.5박 모드 · 연차 컨설팅(연간 분배)
- **동반유형 필터(연인·가족)** — 공공데이터 부재, 자체 LLM 태깅 필요
- 커뮤니티/리뷰 · AI 개인화 · 예약 연동
- 자체 콘텐츠 레이어(이미지 CDN·큐레이션) — 데이터 레이어 설계에서 별도
