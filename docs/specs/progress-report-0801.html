#작업이 작업으로 사용자가 할 수 있는 것
1 서버에 로그인 없이는 못 들어오게 막기 서버를 외부에 열기 전에 아이디·비밀번호를 모르면 아무도 못 쓰게 했다. 그전에는 주소만 알면 누구나 우리 서버를 통해 관광·길찾기 데이터를 뽑아 쓸 수 있었다. 길찾기(TMAP)는 하루 50번까지만 무료라 봇 하나가 몇 초면 하루치를 다 태울 수 있는 상태였다. 브라우저로 접속하면 로그인 팝업이 뜬다.
2 서버 자동 배포 준비 (EC2 · MySQL) 화면 변화는 없다. 코드를 올리면 서버에 자동으로 반영되는 길을 만들었다 — 클라우드 서버에 데이터베이스를 띄우고, 배포용 계정·접속 권한·비밀값 11개를 등록했다. 배포가 잘못됐을 때 이전 버전으로 되돌릴 수 있게 해뒀고, 첫 배포만 사람이 직접 눌러 확인한 뒤 자동으로 전환한다.
3 버스 정보 없는 지역을 "버스 없음"과 구분 정선·평창처럼 버스 정보가 제공되지 않는 13곳에서 "여긴 대중교통이 어려워요"라고 잘못 안내하던 것을 고쳤다. 정선에 버스가 없는 게 아니라 국가 교통정보에 데이터가 없는 것이라, 이제 "대중교통 정보 없음"으로 다르게 표시된다. 이름이 같은 강원 고성군과 경남 고성군도 서로 섞이지 않게 갈라냈다.
