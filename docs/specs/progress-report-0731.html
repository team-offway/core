오늘 9건 작업

#작업이 작업으로 사용자가 할 수 있는 것
1 내 연차 저장 · 조회 · 수정 연차가 저장되기 시작했다. 내 연차 화면에서 총 연차를 고치고 사용 내역을 쌓을 수 있고, 홈 상단 "남은 연차"도 저장된 값을 보여준다. 그전엔 화면이 보낸 숫자를 그대로 돌려주기만 해서 새로고침하면 사라졌다.
2 코스 확정 시 연차 차감 코스를 확정하면서 "연차를 차감할까요?"를 누르면 그 여행 기간만큼 실제로 연차가 빠진다. 며칠 빠지는지는 서버가 저장된 여행 날짜로 다시 계산해서, 화면이 보낸 값을 그대로 믿지 않는다. 실수로 두 번 눌러도 한 번만 차감된다.
3 홈 진입 모달 — 지난 여행 "다녀오셨나요?" 여행이 끝난 다음 날부터 홈에 들어가면 "○○ 다녀오셨나요?"가 먼저 뜨고, 답하면 연차가 정리된다. 원래는 사용자가 내 코스 화면에 직접 들어가 버튼을 눌러야 했는데, 다녀온 직후에 그 화면에 들어갈 이유가 없어 잔액이 계속 틀린 채 남았다.
4 계획 관리 — 연차↔코스 정합성 + 목록 강화 차감을 취소할 수 있고, 코스를 지우면 그 코스로 빠진 연차도 함께 되돌아온다. 그전엔 코스를 지우면 연차가 깎인 채 되돌릴 방법이 아예 없었다. 코스 목록에 여행 날짜가 실려서 "다가오는 여행 / 지난 여행" 구분과 D-day 표시가 가능해졌다.
5 코스 재생성 — 기존과 다른 코스로 코스가 맘에 안 들면 다시 돌려 다른 코스를 받을 수 있다. "이 장소는 빼줘"도 지정할 수 있다. 장소를 무작위로 섞는 게 아니라 뭉치는 기준점만 바꿔서, 다른 코스가 나오면서도 동선이 흩어지지 않는다.
6 내 코스 삭제 저장한 코스를 지울 수 있다(코스 삭제하기 버튼). 남의 코스 ID를 넣어보는 방식으로 "그 코스가 존재하는지"를 알아낼 수 없게, 없는 코스와 남의 코스를 똑같이 처리한다.
7 버스 데이터 없는 지역을 "버스 없음"과 구분 PR 예정 정선·평창처럼 버스 정보가 제공되지 않는 13곳에서 "여긴 대중교통이 어려워요"라고 잘못 안내하던 것을 고쳤다. 정선에 버스가 없는 게 아니라 국가 교통정보에 데이터가 없는 것이라, 이제 "대중교통 정보 없음"으로 다르게 표시된다.
8 첫 접속이 몰릴 때 빈 화면·오류가 나던 문제 서버를 켠 직후나 캐시가 비는 순간에 여러 명이 동시에 들어오면, 한 명은 정상인데 다른 한 명은 오류나 빈 화면을 받았다. 이제 진행 중인 조회 결과를 나눠 갖는다. 재현이 어려워 조용히 넘어가던 종류의 문제다.
9 테스트가 실제 외부 API를 호출하던 것 차단 화면 변화는 없다. 길찾기 API 하루 사용량(50건)의 80%가 테스트로 소진되고 있었다 — 성공 응답이라 로그에도 흔적이 없었다. 테스트에서 키 자체를 못 보게 막아, 앞으로 실수로 빠뜨려도 사용량이 새지 않는다.
