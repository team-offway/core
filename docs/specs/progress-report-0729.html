오늘 4건 작업

#작업이 작업으로 사용자가 할 수 있는 것
1 코스 카드를 트리플식으로 — 각 장소에 추천 한 줄·썸네일 코스에 나온 장소마다 썸네일 이미지 · 카테고리(관광·맛집·숙박) · 위치 · "추천 한 줄"이 카드에 함께 뜬다 (예: 완도타워 → 바다 위에 뜬 낭만, 완도의 랜드마크). 장소를 눌러 상세로 안 들어가도 타임라인만으로 뭐가 뭔지 바로 읽힌다.
2 코스에 끼니·숙소가 항상 들어가게 코스에 관광지만 나오던 지역(음식점·숙박이 적은 시골)에서도 점심·저녁 맛집과 잘 곳이 빠지지 않고 일정에 들어간다. 하루가 "관광 → 점심 → 관광 → 저녁 → 숙소"로 채워진다.
3 버스 정류소·도착정보 연동토대 여행 당일 근처 정류소와 다음 버스가 언제 오는지를 알 수 있는 토대를 붙였다. 실시간 값이라 "이미 떠난 버스"를 안 보여주도록 처리. (대중교통 코스 실측에 연결 예정)
4 API 문서에 화면→코스 흐름 설명개발 사용자 화면 변화는 없음. 프론트·협업자가 API 문서(Swagger) 첫 화면에서 홈 → 연차 → 여행지 추천 → 코스 생성 → 장소 상세까지 "무엇을 호출해 무엇을 받아 어떻게 잇는지"를 한눈에 본다.
